# SISTEM MONITORING STOK DAN PENJUALAN KANTIN KAMPUS

## Deskripsi Program
Program ini merupakan aplikasi sederhana berbasis bahasa C yang dibuat untuk membantu mengelola stok produk dan transaksi penjualan di kantin kampus.

## Tujuan
1. Mempermudah pengelolaan data produk.
2. Memantau persediaan stok barang.
3. Mencatat transaksi penjualan.
4. Mengetahui total pendapatan.
5. Mempermudah pencarian dan pengurutan produk.

## Fitur Program
Program memiliki beberapa fitur utama:

1. Lihat Daftar Produk
2. Tambah Produk
3. Ubah Produk
4. Transaksi Penjualan
5. Tambah Stok
6. Cari Produk
7. Urutkan Produk
8. Laporan Penjualan
9. Cek Stok Menipis
10. Keluar

## Bahasa Pemrograman
- Bahasa C
- Code::Blocks

## Data Produk
Produk awal yang tersedia:
- Nasi Goreng
- Mie Ayam
- Es Teh Manis
- Gorengan
- Air Mineral
- Kopi Susu

Pengguna juga dapat menambahkan produk baru.

## Cara Menjalankan Program
1. Download repository ini.
2. Buka file `main.c` menggunakan Code::Blocks.
3. Klik Build and Run.
4. Program akan menampilkan menu utama.
5. Pilih menu sesuai kebutuhan.
   

## Kesimpulan
Program ini dibuat untuk membantu proses pengelolaan stok dan penjualan kantin kampus agar lebih mudah, cepat, dan teratur.
